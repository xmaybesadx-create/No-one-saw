# Workflow

Even as a solo project, work like a team: it keeps history clean and shows the process.

## Branches
- `main` is always working.
- One short-lived branch per issue: `feat/interrogation-topics`, `fix/accusation-check`, `docs/stack`.

## Commits
Use [Conventional Commits](https://www.conventionalcommits.org/): `feat:`, `fix:`, `docs:`, `refactor:`, `test:`, `chore:`.

## Pull requests
- Link the issue (`Closes #12`).
- Keep PRs small and focused; squash merge.
- Update docs and ADRs when a decision changes.

## Planning
- Goals live in GitHub **Milestones** (M0-M5), each with a "Definition of Done".
- Tasks live in **Issues** on the project board.
